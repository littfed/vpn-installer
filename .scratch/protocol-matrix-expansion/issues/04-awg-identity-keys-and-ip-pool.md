# 04: Расширение модели Identity: генерация Curve25519-ключей и IP-пула для AWG

**What to build:**
Расширение команды управления пользователями `vpn user add <name>` и файла реестра `users.json` для поддержки AmneziaWG. При создании пользователя генерируется криптографическая пара ключей Curve25519 (`private_key`, `public_key`) и выделяется следующий доступный внутренний IPv4-адрес из подсети туннеля `10.8.0.0/24` (начиная с `10.8.0.2`). При удалении пользователя (`vpn user del <name>`) его адрес возвращается в пул. Данные сохраняются атомарно.

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] В `bin/vpn` и сопутствующих скриптах управления пользователями реализована генерация ключей Curve25519 (через `awg genkey` / `wg genkey` или встроенные средства Python/OpenSSL).
- [x] Реализован распределитель IP-адресов из диапазона `10.8.0.2` – `10.8.0.254`.
- [x] Структура каждого пользователя в `users.json` дополнена объектом `awg`:
  ```json
  "awg": {
    "private_key": "<base64-curve25519-private>",
    "public_key": "<base64-curve25519-public>",
    "ip": "10.8.0.X/32"
  }
  ```
- [x] Существующие пользователи без блока `awg` автоматически мигрируются при первом запуске `vpn user list` или `vpn user sync` с генерацией ключей и выделением IP без нарушения существующих UUID/паролей.
