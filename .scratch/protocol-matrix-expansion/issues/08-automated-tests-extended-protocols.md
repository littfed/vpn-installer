# 08: Сквозные автоматизированные тесты для TUIC v5 и AmneziaWG

**What to build:**
Набор автоматизированных тестов в `tests/test_extended_protocols.py`, обеспечивающий 100% покрытие новой функциональности: инбаунда TUIC v5 в sing-box, распределения IP и Curve25519-ключей для AmneziaWG, генерации конфигураций `awg0.conf`, доставки подписок `?format=awg` и `?format=singbox` / `clash`, а также корректной работы синтетических проверок и Circuit Breaker для обоих протоколов.

**Blocked by:** 03: Зондирование TUIC v5 в Canary Probe и CLI, 07: Синтетический UDP Handshake Probe для AmneziaWG

**Status:** ready-for-agent

- [ ] Тесты генерации конфигурации sing-box: проверяется наличие инбаунда `type: tuic` с портами, шифрованием BBR и пользователями.
- [ ] Тесты управления пользователями AWG: проверяется создание ключей Curve25519, инкрементное выделение IP `10.8.0.X` и возврат IP в пул при удалении.
- [ ] Тесты рендеринга `awg0.conf`: проверяются параметры обфускации `H1–H4`, `Jc`, `Jmin/Jmax`, `S1/S2` и секции пиров.
- [ ] Тесты сервера подписок `sub-server.py`: валидируются ответы на запросы `?format=awg` (корректность синтаксиса WireGuard INI) и `?format=singbox` / `clash` (наличие TUIC v5 в селекторах `AUTO-FASTEST`).
- [ ] Тесты `canary-probe.py`: мокируются сетевые вызовы TUIC и AWG UDP Handshake, проверяются переходы состояний `healthy` <-> `degraded` в `node-health.json`.
- [ ] Все тесты выполняются без внешних сетевых зависимостей и успешно проходят в общем прогоне `pytest tests/`.
