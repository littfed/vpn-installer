# Спецификация: Мониторинг доступности зарубежных нод из РФ (Canary Probe)

## 1. Контекст и проблематика
При блокировках со стороны ТСПУ / РКН доступность зарубежных VPN-нод может деградировать частично (например, фильтрация UDP-трафика Hysteria 2 на порту 443 при сохранении TCP VLESS Reality, либо блокировка отдельных диапазонов IP-адресов зарубежных хостеров). Внешний мониторинг из Европы или США видит ноду полностью здоровой, в то время как пользователи внутри РФ сталкиваются с разрывом связи.

Для обеспечения высокой отказоустойчивости создается контрольный агент внутри РФ (**Canary Probe**) на базе сервера управления в РФ.

## 2. Архитектура решения
1. **Canary Engine (`scripts/canary-probe.py`)**:
   - Автономный легковесный скрипт на Python 3.
   - Для тестирования VLESS Reality и Hysteria 2 поднимает локальный временный процесс `sing-box` (версии 1.14+) с изолированным портом socks/mixed на `127.0.0.1`.
   - Проводит трехточечную проверку:
     - `https://cp.cloudflare.com/generate_204` (замер RTT задержки).
     - `https://www.youtube.com` / `https://www.instagram.com` (обход блокировок ТСПУ).
     - `https://api.openai.com` (проверка работоспособности WARP egress ноды).
   - Для MTProto Proxy выполняет TCP handshake к порту 8443.
2. **Circuit Breaker (`node-health.json`)**:
   - Порог отключения: 2 последовательных сбоя переводят протокол/ноду в статус `degraded`.
   - Порог восстановления: 2 последовательных успешных теста переводят в статус `healthy`.
   - Защита от флаппинга при кратковременных потерях пакетов.
3. **Интеграция с подписками (`scripts/sub-server.py`)**:
   - При выдаче подписок клиентам (Clash YAML, Sing-box JSON, Base64) эндпоинт читает `node-health.json`.
   - Деградировавшие или недоступные протоколы автоматически исключаются из группы `AUTO-FASTEST` / `proxy-auto` и переводятся в резерв (fallback).
4. **Интерфейс оператора и автоматизация**:
   - CLI: `vpn probe` — ручной запуск диагностики с выводом понятной сводной таблицы в консоль.
   - Фоновый процесс: `systemd` таймер (`vpn-canary.timer`) с интервалом 7 минут и рандомизированным джиттером ±60 сек для защиты от анализа периодичности сетевого трафика.

## 3. Требования к безопасности
- Никаких секретов, паролей, приватных ключей или реальных IP-адресов в коде и репозитории.
- Вся конфигурация нод считывается из локального `nodes.json` / `manifest.json`.
- Временные конфигурационные файлы sing-box сохраняются во временной директории с правами `0600` и удаляются сразу после завершения замера.
