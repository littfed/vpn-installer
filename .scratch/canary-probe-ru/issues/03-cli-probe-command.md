# 03: Интеграция команды диагностики в CLI (vpn probe)

**What to build:**
Команда CLI `vpn probe` (или `vpn node check`), позволяющая администратору или оператору вручную запустить диагностику доступности зарубежных нод из РФ в реальном времени с выводом аккуратной форматированной таблицы результатов в терминал.

**Blocked by:** 01: Движок синтетического зондирования на базе sing-box, 02: Реестр здоровья нод и логика Circuit Breaker

**Status:** resolved

## Acceptance criteria

- [x] В `bin/vpn` реализована подкоманда `vpn probe` (с алиасом `vpn node test`).
- [x] Поддерживаются флаги:
  - `--node <name>` — тестирование конкретной ноды (по умолчанию тестируются все ноды из `nodes.json`).
  - `--protocol <vless|hy2|mtproto>` — тестирование конкретного протокола.
  - `--json` — вывод результатов в сыром формате JSON (для скриптов и внешних систем).
- [x] В интерактивном режиме в терминал выводится сводная таблица:
  ```text
  +------------+----------------+----------+---------+---------+-----------+
  | Node       | Protocol       | Latency  | TSPU    | WARP    | Status    |
  +------------+----------------+----------+---------+---------+-----------+
  | Node-1     | VLESS-Reality  | 42 ms    | OK      | OK      | HEALTHY   |
  | Node-1     | Hysteria 2     | 38 ms    | OK      | OK      | HEALTHY   |
  | Node-1     | MTProto        | 40 ms    | OK      | -       | HEALTHY   |
  | Node-2     | VLESS-Reality  | 45 ms    | OK      | OK      | HEALTHY   |
  | Node-2     | Hysteria 2     | FAIL     | BLOCKED | -       | DEGRADED  |
  +------------+----------------+----------+---------+---------+-----------+
  ```
- [x] При наличии флага ошибки (например, сбой всех протоколов ноды) команда завершается с ненулевым кодом выхода `1`.
- [x] Справка `vpn help` обновлена с описанием команды `vpn probe`.
