# 08: Сетевой фаервол, Port Hopping, бэкапы (vpn backup/restore) и харденинг

**What to build:**
Комплекс сетевой безопасности и защиты сервера: автоматическая настройка UFW и iptables для Port Hopping (перенаправление диапазона UDP `20000:30000` на порт Hysteria `443/UDP`), блокировка исходящего спама (порты 25, 465, 587) и BitTorrent, реализация команд создания и восстановления бэкапов (`vpn backup` / `vpn restore`), интерактивный вызов харденинга ОС через `littfed/server-setup` (`vpn system harden`) и команда самодиагностики утечек (`vpn test-leak`).

**Blocked by:** 03: Управление жизненным циклом, 04: WARP Egress, 06: MTProto Proxy, 07: Адаптивный эндпоинт подписок

**Status:** resolved

## Acceptance criteria

- [x] В UFW открываются только необходимые внешние порты: `80/TCP`, `443/TCP`, `443/UDP`, `8443/TCP`, диапазон UDP `20000:30000` и текущий SSH-порт.
- [x] Настраивается правило `iptables` / `nftables` для Port Hopping: входящий диапазон UDP `20000:30000` транслируется в локальный порт Hysteria 2.
- [x] В `config.json` активны правила блокировки спама (порты 25, 465, 587, 2525) и BitTorrent хендшейков.
- [x] Команда `vpn backup [path]` упаковывает `users.json`, `manifest.json`, `docker-compose.yml`, `Caddyfile` и кастомные HTML файлы в единый защищённый архив `.tar.gz`.
- [x] Команда `vpn restore <archive>` разворачивает конфигурацию на чистом сервере в одну операцию с перезапуском контейнеров.
- [x] Команда `vpn system harden` интерактивно вызывает процедуры безопасности из репозитория `https://github.com/littfed/server-setup` (настройка SSH, fail2ban, обновления безопасности).
- [x] Команда `vpn test-leak` выполняет быструю самопроверку утечек DNS, WebRTC и статус WARP Egress через консоль.
- [x] Команда `vpn uninstall` корректно останавливает и удаляет контейнеры, очищает правила фаервола и симлинки в `/usr/local/bin/vpn` с запросом сохранения данных.
