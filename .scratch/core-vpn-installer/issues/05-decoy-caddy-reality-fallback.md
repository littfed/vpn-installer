# 05: Сайт-заглушка (Caddy), порт 80 (Let's Encrypt) и Fallback порта 443

**What to build:**
Развёртывание веб-сервера Caddy в Docker Compose рядом с sing-box. Caddy слушает порт `80/TCP` для автоматического получения/обновления сертификатов Let's Encrypt через HTTP-01 challenge и `127.0.0.1:8443` для раздачи реалистичного статического сайта-заглушки. В sing-box настраивается VLESS Reality fallback на `127.0.0.1:8443`, благодаря чему неавторизованные запросы цензоров и браузеров получают легитимный HTTPS-сайт с валидным SSL-сертификатом.

**Blocked by:** 01: Базовый инсталлер и Docker Compose с ядром Sing-box

**Status:** resolved

## Acceptance criteria

- [x] В `docker-compose.yml` добавлен сервис `caddy` с портами `80:80` и `127.0.0.1:8443:8443`.
- [x] В каталоге `/opt/vpn-installer/caddy/html/` разворачивается шаблон реалистичного статического лендинга (HTML/CSS) со строгими заголовками безопасности и `robots.txt`.
- [x] В `Caddyfile` настроено автоматическое получение Let's Encrypt сертификата через порт 80 (HTTP-01) для указанного домена ноды.
- [x] Входящее соединение на `vless-in` (порт 443) без корректных ключей Reality прозрачно передаётся на `127.0.0.1:8443` через директиву `handshake.server` / `handshake.server_port`.
- [x] Сканирование порта `443` через `curl -I https://<domain>` возвращает статус `HTTP/2 200 OK` и валидный TLS-сертификат без утечки каких-либо прокси-заголовков.
- [x] Сканирование порта `80` возвращает валидный HTTP 200/301 ответ.
