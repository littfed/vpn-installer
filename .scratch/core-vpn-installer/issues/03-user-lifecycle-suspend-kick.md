# 03: Управление жизненным циклом пользователя (Suspend, Enable, Kick, Delete)

**What to build:**
Полноценное управление жизненным циклом учётных записей через CLI: возможность временно заморозить доступ (`vpn user suspend <name>`) без удаления реквизитов, возобновить доступ (`vpn user enable <name>`), принудительно разорвать текущие активные сессии (`vpn user kick <name>`) и полностью удалить пользователя (`vpn user delete <name>`).

**Blocked by:** 02: Реестр пользователей и CLI (добавление, просмотр, ссылки и QR-коды)

**Status:** resolved

## Acceptance criteria

- [x] Команда `vpn user suspend <name>` меняет статус пользователя в `users.json` на `suspended`, исключает его из активного `config.json` и отправляет `SIGHUP`. Пользователь больше не может установить новое соединение.
- [x] При заморозке пользователя сохраняются все его сгенерированные ключи и UUID в `users.json`.
- [x] Команда `vpn user enable <name>` возвращает статус `active`, возвращает пользователя в `config.json` и отправляет `SIGHUP`.
- [x] Команда `vpn user kick <name>` выполняет принудительный сброс активных открытых соединений пользователя через Clash API (`DELETE /connections/{id}`) или сетевой стек хоста.
- [x] Команда `vpn user delete <name>` полностью удаляет запись из `users.json` и исключает пользователя из `config.json`.
- [x] Команда `vpn user delete` запрашивает подтверждение (или принимает флаг `--force` / `-y`).
