# 02: Реестр пользователей и CLI (добавление, просмотр, ссылки и QR-коды)

**What to build:**
Подсистема управления пользователями через файл `users.json` и CLI-команды `vpn user add <name>`, `vpn user list`, `vpn user show <name>`. При добавлении пользователя генерируются его персональные реквизиты (UUID, пароли), атомарно обновляется `config.json` с валидацией через `sing-box check` и отправкой `SIGHUP` контейнеру. Команда `vpn user show` выводит готовые валидные ссылки подключения (`vless://`, `hysteria2://`) и терминальные ASCII QR-коды.

**Blocked by:** 01: Базовый инсталлер и Docker Compose с ядром Sing-box

**Status:** resolved

## Acceptance criteria

- [x] Создаётся структура хранения `users.json` со статусом пользователей (`active`), датой создания и учетными данными.
- [x] Команда `vpn user add <name>` генерирует криптографически стойкий UUID и пароли, добавляя пользователя в `users.json`.
- [x] При добавлении пользователя генерируется временный конфиг, проверяется валидатором `sing-box check`, атомарно заменяет `config.json` и отправляет сигнал `SIGHUP` процессу sing-box без падения контейнера.
- [x] Команда `vpn user list` отображает форматированную таблицу пользователей (имя, статус, дата создания).
- [x] Команда `vpn user show <name>` генерирует синтаксически корректные URI:
  - `vless://uuid@ip:443?security=reality&flow=xtls-rprx-vision&pbk=...&sni=...&sid=...&fp=chrome#Name-Reality`
  - `hysteria2://pass@ip:443/?sni=...&obfs=salamander&obfs-password=...#Name-Hy2`
- [x] Команда `vpn user show <name> --qr` выводит читаемый ASCII QR-код в терминал для мобильного сканирования.
- [x] Идемпотентность: повторная попытка добавить существующего пользователя возвращает понятную ошибку и не ломает базу.
