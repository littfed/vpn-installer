# 03: Эндпоинты доставки AmneziaWG: выбор ноды, ZIP-архив и нативный профиль Amnezia

**What to build:**
Расширение сервера адаптивных подписок `scripts/sub-server.py` для раздачи конфигураций AmneziaWG в многосерверной и мульти-девайсной среде. Поддержка параметров фильтрации по ноде и устройству (`?format=awg&node=<name>&device=<device>`), генерация структурированного ZIP-архива (`?format=awg-zip`) с папками по устройствам, а также нативного профиля AmneziaVPN (`?format=amnezia` в виде JSON / протокольной ссылки `vpn://...`) для объединения всех нод в один профиль.

**Blocked by:** 01: Модель данных Multi-Device и расширение подсетей AmneziaWG до /16, 02: Синхронизация пиров устройств в awg0.conf и сетевой стек ноды

**Status:** closed

- [x] Эндпоинт `?format=awg&node=<name>&device=<device>` отдает файл `.conf` с корректными параметрами выбранного сервера и ключами запрошенного устройства.
- [x] При запросе `?format=awg` без параметров по умолчанию отдается конфиг `device-1` для наиболее здорового/быстрого сервера по данным Circuit Breaker (`node-health.json`).
- [x] Эндпоинт `?format=awg-zip` динамически собирает и отдает ZIP-архив с MIME-типом `application/zip` и структурой папок:
  `/device-1/<Node-1>.conf`, `/device-1/<Node-2>.conf`, `/device-2/<Node-1>.conf`...
- [x] Эндпоинт `?format=amnezia` отдает валидный JSON-конфиг приложения AmneziaVPN со всеми доступными контейнерами серверов, либо генерирует ссылку `vpn://...`.
