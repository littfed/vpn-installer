# 04: Автономный Web-портал (Dashboard) подписки

**What to build:**
Полноценный адаптивный веб-портал, открывающийся при переходе по ссылке подписки `https://<domain>/sub/<token>` в обычном браузере. Полностью автономный, одностраничный (HTML/CSS/JS инлайн), в тёмной теме, без внешних CDN, веб-шрифтов и трекеров (работает при блокировках внешнего интернета). Предоставляет пользователю мониторинг нод, 1-click импорт в приложения (Sing-box, Clash, Shadowrocket, Streisand, Amnezia), копирование прямых ссылок (TUIC, VLESS, Hy2, MTProto), генератор SVG QR-кодов прямо в браузере и раздел AmneziaWG с переключением устройств, скачиванием `.conf` и ZIP-архива.

**Blocked by:** 03: Эндпоинты доставки AmneziaWG: выбор ноды, ZIP-архив и нативный профиль Amnezia
