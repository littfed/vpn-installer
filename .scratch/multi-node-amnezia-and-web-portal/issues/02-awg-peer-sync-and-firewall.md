# 02: Синхронизация пиров устройств в awg0.conf и сетевой стек ноды

**What to build:**
Сквозная синхронизация всех активных устройств пользователей в конфигурационный файл серверного интерфейса `awg0.conf`. Каждое устройство каждого активного пользователя отрисовывается как отдельная секция `[Peer]` с собственным публичным ключом и `AllowedIPs = 10.8.X.Y/32`. Обновление правил межсетевого экрана и NAT MASQUERADE для маршрутизации расширенного диапазона `/16`. Безопасная горячая перезагрузка контейнера `amneziawg`.

**Blocked by:** 01: Модель данных Multi-Device и расширение подсетей AmneziaWG до /16
