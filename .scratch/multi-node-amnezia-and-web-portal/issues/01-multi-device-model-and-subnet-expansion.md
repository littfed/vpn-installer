# 01: Модель данных Multi-Device и расширение подсетей AmneziaWG до /16

**What to build:**
Расширение адресного пространства AmneziaWG до пула `/16` (до 65 534 адресов на сервер) с раздельными диапазонами по серверам (Node-1: `10.8.1.X`, Node-2: `10.8.2.X`), исключающее конфликты маршрутов в роутерах при Multi-WAN / Failover. Обновление логики создания пользователей: `vpn user add <name>` автоматически выделяет 2 устройства по умолчанию (`device-1` и `device-2`) с независимыми ключевыми парами Curve25519 и разными IP. Добавление CLI-команд `vpn user device add <user> <device>` и `vpn user device del <user> <device>`. Бесшовная миграция существующих пользователей в `users.json`.

**Blocked by:** None (can start immediately)

**Status:** closed

- [x] В `bin/vpn` подсеть AmneziaWG расширена до `/16`, пул адресов выделяется динамически без коллизий между устройствами одного пользователя и между пользователями.
- [x] Команда `vpn user add <name>` автоматически создает в структуре пользователя объект `devices` с двумя готовыми слотами: `device-1` и `device-2`, каждый со своей ключевой парой Curve25519 и адресом `10.8.X.Y/32`.
- [x] Реализованы команды `vpn user device add <user> <device>` и `vpn user device del <user> <device>` для динамического добавления/удаления дополнительных устройств (роутер, ноутбук, планшет).
- [x] Реализована автоматическая миграция: при чтении старого `users.json`, где у пользователя был только один ключ `awg`, он автоматически сохраняется как `device-1`, и генерируется `device-2`.
- [x] Команда `vpn user show <name>` обновлена: поддерживает флаг `--device <name>` (по умолчанию выводит список всех устройств или `device-1`) с выводом соответствующих `.conf` и QR-кодов.
